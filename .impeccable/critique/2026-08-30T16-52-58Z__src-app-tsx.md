## Design Specificity Verdict

**LLM assessment: Split-world product.** The app has two incompatible visual worlds stitched together: the main app renders a warm-cream/near-black "terminal-native" look (Berkeley-Mono heritage per DESIGN.md) over rounded-xl cards, hover glow gradients and a teal glass widget (`#38f8df`) that belongs to an entirely different brand. The terminal aesthetic is half-implemented: `--font-sans` names 'JetBrains Mono' which is **never imported**, while Source Sans 3 and Figtree are imported but never referenced by the theme — body text silently falls back to Geist Mono. The result reads accidental, not authored. The Dictation page could belong to any analytics dashboard; nothing says "voice."

**Deterministic scan:** 108 findings (12 warnings, 96 advisory) across 17 files. Heaviest: `widget.css` (27 — off-palette teal/green colors, off-ramp 10px type), `models.tsx` (21 — off-system type/color/radius drift), `index.css` (8), `home.tsx` (8), `transcripts.tsx` (6), `onboarding.tsx` (5). 76 font-size drift findings dominate — the type ramp isn't governing real usage. Detector corroborates the split-world: widget.css is the single largest drift source. False positives: none material; advisories in charts/calendar are legitimate.

## Overall Impression

Solid engineering underneath (exceptional failure-recovery architecture) wearing an unresolved identity: half terminal-cult, half rounded SaaS dashboard, plus a teal widget from a third product. Home page over-delivers everything at once. Biggest opportunity: commit to ONE voice-visual world and let the record action own the screen.

## What's Working

1. **Engine fallback UX** — fallback/transcription-engine changes surface as warnings with reasons, and failed transcription keeps the audio file with a retry action. Rare and valuable.
2. **State feedback discipline** — status pills, update-install progress with %, dictation widget pill, tabular-nums/mono chips for numeric data.
3. **Token architecture** — full light/dark token system with semantic naming; drift is fixable cheaply because it diverges from a real system.

## Priority Issues

1. **[P1] Destructive delete with zero friction.** Trash icon instantly deletes a transcript: no undo, no confirm, no toast. Retention pruning also deletes silently. Fix: optimistic remove with 5s undo toast ("Transcript deleted — Undo"), confirm on empty-all.
   - Suggested command: `$impeccable harden`
2. **[P1] Half-implemented typographic identity.** JetBrains Mono named but never loaded; Source Sans 3 + Figtree imported and ignored; 76/108 detector findings are off-ramp font sizes. UI body copy in mono hurts scanability at small sizes. Fix: decide (mono = brand accent only, sans = reading) and rebuild the ramp at 4 steps.
   - Suggested command: `$impeccable typeset` → then `$impeccable document`
3. **[P1] "Check Engine" jargon + duplicated status.** Car-diagnostic metaphor for "verify native host"; engine state appears in the Command Card button AND the "Current setup" panel rows with different values ("Ready" vs statusLabel). Fix: one inline status chip near the record button ("Ready — Apple Speech"); delete the other.
   - Suggested command: `$impeccable clarify`
4. **[P2] Dashboard-everything home.** Record card, 4 stats, streak panel, setup panel, activity heatmap + 5 analytics charts, 6 transcript cards, latest transcript — one scroll, four "most important" things. Fix: record + latest transcript above the fold; move history/analytics to their existing pages.
   - Suggested command: `$impeccable distill`
5. **[P2] Widget/app brand incoherence.** Teal-glow glass capsule vs warm cream terminal app. Fix: re-skin widget with the committed palette in redesign (or embrace teal as THE accent app-wide — but pick one).
   - Suggested command: handled inside a redesign (`$impeccable shape` → new-work)

## Persona Red Flags

**Alex (Power User):** Copy/delete buried behind hover-reveal (opacity-0 group-hover) — discoverable but hover-dependent; no transcripts search/filter/keyboard nav on home; "Transcribe Last" only on home. Otherwise strong: hotkey-first, hands-free mode.

**Sam (Accessibility):** Hover-revealed actions lack a persistent visible state until focused (opacity flips on group-hover — focus-within not verified); red/green distinction in toasts (tone: success|warning) must not be color-only; custom ScrollAreas need keyboard scroll verification; icon-only copy/delete buttons have aria-labels — good.

**Jordan (First-Timer):** "Check Engine", "CGEventTap", "whisper/parakeet" untranslated; onboarding exists (good) but post-onboarding home offers 3 buttons + 4 sections with no "just press the hotkey" moment.

## Minor Observations

- `--font-sans` references 'JetBrains Mono' which is not imported by any fontsource import — fallback drift risk.
- `surface-depth`/`surface-depth-soft` utilities are `box-shadow: none` — dead tokens.
- Two duplicate "Engine" rows conceptually in Current setup panel (Engine row + native status row).
- Delete buttons across `transcripts.tsx` and home cards should share one pattern.
- 182-day heatmap computed on every render from up to 1000 rows — fine now, memoize under redesign.
